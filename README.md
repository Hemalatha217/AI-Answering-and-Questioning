# 🤖 AI Answering and Questioning

An AI-powered Question Answering app built using Streamlit and Hugging Face.

## 🚀 Live Demo

https://ai-answering-and-questioning-9v5fnnrhu5wkorsoardjar.streamlit.app/

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face
- Qwen/Qwen2.5-0.5B-Instruct

## ✨ Features

- Ask questions in natural language
- Get AI-generated answers
- Simple and user-friendly interface
